# Technical audit, November 2026

Scope: technical correctness, code hygiene, tests, GitHub and Cloudflare setup of
the app as merged in PR #2 (`main` at `01a93ff`). Features were not changed beyond
the fixes listed here. Every claim below is backed by a test in the repository or
by a command whose output was reproduced by an independent reviewer.

## Method

1. Four independent reviews of `main`, without access to each other's results:
   core logic against `docs/SPEC.md` / `docs/LEGACY-IMPORT.md`; UI and AI code;
   a browser test of the production build (Playwright, 360/390/430 px); repository,
   deployment and security.
2. Every finding was re-checked against the code and classified as confirmed bug,
   clean-up item or no problem.
3. Each confirmed bug got a regression test (`src/regressions.test.ts`, `e2e/`)
   and a minimal fix.
4. Two further independent reviewers checked the result: one re-ran all checks on
   a fresh clone and reverted each fix in turn to prove that its test then fails
   ("mutation check"); one reviewed the diff against `main` adversarially. Their
   follow-up findings were fixed as well (last two commits).

  `docs/`, `legacy/` and Markdown are excluded on purpose), `npm run test:e2e`.

## Verification results (independent verifier, fresh clone)

All green: `npm ci`, `typecheck`, `lint`, `format:check`, unit tests, `build`,
`test:e2e`, `npm audit --omit=dev` (0 vulnerabilities). `dist/` contains no
`legacy/` files and no source maps. Mutation check: reverting each of the 14 fixes
made its named test fail. Two gaps found there are closed: the 84-day plateau
boundary now has a test, and Playwright no longer reuses an already running
preview server (which had once served a stale build). After that, the e2e suite
passed 36/36 runs (3 repetitions) and the unit suite 34/34.

## Checked and found correct

- No secrets or personal data in the working tree or the full git history;
  `docs/legacy/sample-export.json` is marked synthetic. Backups never contain the
  OpenRouter key; import keeps the device's key.
- Dexie schema unchanged (v1). Backup import is atomic (rollback tested).
- Formulas (Epley/Brzycki, % → kg rounding, plates, PRs, volume), Zurich dates,
  index usage, AI validation and the explicit-tap rule.
- Cloudflare Pages: default `Cache-Control: max-age=0, must-revalidate` for
  `index.html`/`sw.js` (updates arrive), root fallback for unknown paths (hash
  routes make it irrelevant), `[CF-Pages-Skip]` commit prefix works as intended.
  Do not add a `404.html`: it would disable the root fallback.
- Production dependencies: no known vulnerabilities. The remaining `npm audit`
  findings are build-time only (`vite-plugin-pwa` → `workbox-build`); `npm audit fix`
  does not resolve them without a major upgrade.
